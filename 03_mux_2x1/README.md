# 2:1 Multiplexer using Verilog HDL

## Objective

Design and verify a 2:1 Multiplexer using Verilog HDL.

## Description

A 2:1 Multiplexer selects one of two inputs based on the select signal.

Inputs:
- i0
- i1
- sel

Output:
- y

## Truth Table

| sel | Output |
|------|--------|
| 0 | i0 |
| 1 | i1 |
